Burning DVDs with DVDIt!

Setup:

Sony VAIO RX690g (PC)
DVDIt! 2.5 PE (upgraded from version bundled with VAIO)
Pioneer DVR-AO4 DVD-RW writer (bundled with VAIO)
Adobe Premiere 6.0 LE (bundled with VAIO)
Use DVDIt! for transcoding WAV, AVI ==> MPEG2

Problems creating DVDs from Mac-created MOV files

  • Renamed "chapter1.MOV" ==> "chapterone.mov"
    My brother and I had a TON of trouble importing his MOV files (which were taken directly from a IDE MAC drive using a free trial of a "drive translator" software package) Importing was very unreliable -- sometimes the MOV file would go, sometimes DVDIt! would crash. Some files would never input. It took us 3 days of fighting to try renaming the files. IT WORKED! However, we then found that the built in conversion from MOV ==> AVI in DVDIt! produced very bad looking video. So next we realized we should convert MOV to AVI using Premiere first (see next item.)
  • First convert MOV to AVI using Premiere When we had Apple-created MOV files and finally could import them to DVDIt!, it turns out whatever it does to convert to AVI looked bad. So use Premiere (if you have it) instead.
  • For whacked out estimations, select "USER" for media When we were importing Apple-created MOV files, the "calculate project size" was so inflated that we determined it was wrong (and proved that later.) Thus, we needed to tell it that 60 minutes of 8.0Mbps AVIs should fit just fine on a DVD-R. (It was saying it needed 8GB!) It took a lot of thrashing, but we finally figured out how to use the silly "USER" media size. Select it from the pulldown and then **TYPE IN A NUMBER** in the select box. The number we used was either 8.2 (for GB) or 8000 (for MB.) That worked! Once transcoded, the build was 4.3GB (and not 8GB) (We expect about a 3-to-1 compression from the sum of the AVI/MOV file sizes to the DVD output size as a ballpark guide.)

General

  • Success burning
    I've been able to burn TDK DVD-R, Memorex DVD-R and DVD-RW blanks. I haven't burnt a coaster yet! (Crossing fingers) I've burned 4 DVD-Rs overall, and 20-30 DVD-RWs. I use the DVD-RW to test the burn first (DVDIt! can abort a build if it can't find files, etc. However, usually if it makes it to the "Writing Files" stage, you are good to go!)
  • Do NOT leave extra movies in "movies list"
    (not the "media" tab in "themes") I found that when there are extra movies in the movies list which aren't linked, my build often fails (with the mysterious "build failed, ERR -255" and such) at the end of everything being transcoded OR right before it would burn to CDR/DVD. I am guessing that it thinks it should link the movie into the project but doesn't know how to do so. This is just a superstion/guess. The last cDVD that I burned failed and when I removed an extra movie, it succeeded!
