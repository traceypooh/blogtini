# Your blog, as plain text files. Forever.

Write in markdown. Keep it in a free git repo. blogtini paints it with javascript, right in the browser -- in any of 13 themes. No JS, no network, 1000 years from now? Still a readable text file.

Live preview themes →
Get started All the themes GitHub
**No build step required.** (An optional one makes it better.) - Each post is one file: a title, date & tags up top, then markdown. - One word in `config.yml` picks your theme -- & visitors can try the others, live. - Free hosting w/ GitHub Pages. Comments arrive as pull requests. No server, no database. - Search, tags, categories, RSS, light & dark -- all built in. Start your own in 2 minutes: the [blogtini-go](https://github.com/traceypooh/blogtini-go) template.
