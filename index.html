# Your blog, as plain text files. Forever.

Write in markdown. Keep it in a free git repo. blogtini paints it with javascript, right in the browser -- in any of 15 themes. Like a static site generator, except the generating happens in your visitor's browser. No JS? No network? 1000 years from now? Still a readable text file.

**No build step required.** (An optional one makes it better.) - Each post is one file: a title, date & tags up top, then markdown. - Edit a post or page, reload: there it is -- nothing to rebuild. - One word in `config.yml` picks your theme -- & visitors can try the others, live. - Free hosting w/ GitHub Pages. Comments arrive as pull requests. No server, no database. - Search, tags, categories, RSS, light & dark -- all built in. **Start your own in 2 minutes: the [blogtini-go](https://github.com/traceypooh/blogtini-go) template.** 100% open source -- search by [lunr](https://lunrjs.com/), markdown by [showdown](https://github.com/showdownjs/showdown). Want to help build it -- a theme, a fix, an idea? [Here's how](https://github.com/traceypooh/blogtini/blob/main/CONTRIBUTING.md).
