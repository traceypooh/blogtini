Fail-open tests

Shortest top line: <!DOCTYPE html><title>…</title><meta…><style>body{animation:h 3s}@keyframes h{0%,to{visibility:hidden}}</style> — no html/head/body tags.

  • nojs — blank ~3s, then raw markdown (lines run together)
  • nojs-prewrap — same, line breaks kept
  • js-fast — JS renders at 1s, markdown never seen
  • js-slow — JS at 5s: raw markdown at 3s, swapped at 5s; check CLS
  • shift-control — not a fail-open test: a page that definitely shifts, so cls.js can prove it measures

CLS for every page, JS on and off: test/fail-open/cls.js (on a Mac: CHROME='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' test/fail-open/cls.js)

Also try nojs with JS disabled in DevTools (Cmd-Shift-P → "Disable JavaScript") on js-fast: should behave like nojs.
